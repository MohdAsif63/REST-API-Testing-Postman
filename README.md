# REST API Testing - Postman

This project contains API testing practice using Postman and DummyJSON APIs.

## APIs Tested

### 1. User Login
- Tested POST login API.
- Validated HTTP status code (200).
- Extracted access token and refresh token from the response.
- Stored tokens as collection variables.

### 2. Get Current Auth User
- Tested GET current user API.
- Used Bearer Token authentication.
- Validated status code and Content-Type header.
- Checked API response time.

### 3. Refresh Auth Session
- Tested POST refresh token API.
- Passed refresh token and expiry time in the request body.
- Practiced token refresh workflow.

## Testing Skills
- REST API Testing

- Bearer Token Authentication
